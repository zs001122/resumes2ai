# AI 简历筛选工作台

这是一个面向 HR 的 AI 简历筛选工作台 MVP 项目。

当前技术栈：

- 前端：Next.js + TypeScript + Tailwind CSS
- 后端：FastAPI + Python + SQLAlchemy
- 数据库：SQLite，后续可替换 PostgreSQL
- 文件存储：本地 `backend/uploads`

核心设计文档位于 `docs/`。
