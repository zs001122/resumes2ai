# AI 简历筛选工作台 MVP 使用与验收指南

本文档用于 Phase 6 端到端联调和 MVP 验收。

## 1. 启动服务

后端：

```powershell
cd backend
.\venv\Scripts\Activate.ps1
alembic upgrade head
uvicorn app.main:app --reload --port 8010
```

前端：

```powershell
cd frontend
npm run dev
```

默认访问：

```text
http://localhost:3000
```

## 2. 主流程验收

1. 进入岗位列表，创建一个岗位。
2. 填写岗位名称和 JD，点击“解析 JD”，确认筛选标准可人工修改。
3. 保存岗位后进入岗位详情。
4. 上传 PDF、DOCX 或 TXT 简历，单个文件不超过 10MB。
5. 上传完成后查看解析结果。
6. 对解析成功的候选人进入“解析结果修正”，对照原简历修改字段并保存。
7. 点击“重新评分”，确认匹配分、推荐等级、匹配点、短板、风险点和面试问题可更新。
8. 进入候选人列表，确认候选人按匹配分排序，可按状态、推荐等级和最低分筛选。
9. 修改候选人状态，确认状态流转可保存。
10. 进入候选人详情，确认结构化信息、原简历预览和 AI 分析可查看。

## 3. 异常验收

- 岗位列表、岗位详情、候选人列表、候选人详情加载失败时，页面显示错误提示和“重试”入口。
- 未填写岗位名称或 JD 时，创建岗位页显示表单校验提示。
- 上传不支持格式或超过 10MB 文件时，页面显示明确错误。
- 简历解析失败时，上传结果中保留失败记录，并提供“重新解析”入口。
- AI 评分失败时，后端使用本地规则兜底生成临时评分；候选人详情和修正页仍保留“重新评分”入口。
- 候选人工作年限输入非数字时，修正页阻止保存并提示原因。

## 4. MVP 通过标准

- 可以从创建岗位跑到候选人状态流转。
- 常见异常有清晰提示。
- 上传失败、解析失败、AI 评分失败都有可恢复入口。
- MVP 不扩展完整人才库、多人协作、招聘数据大屏、外部招聘平台导入和面试日程管理。
